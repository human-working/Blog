## Machine Learning Development

Modern social media analytics systems utilise sentence-transformers embeddings to generate semantic representations of posts. These embeddings allow the system to understand the meaning of content rather than relying on keywords alone, enabling more accurate and personalised post recommendations.

For this project, we use the Sentence-Transformers library, an open-source framework built on top of Transformer-based language models for generating high-quality text embeddings.

Official documentation: https://www.sbert.net/

## BERT vs GPT

🧠 BERT
- bidirectional (reads text both directions)
- used for understanding
- good for embeddings (like your project)

Example use:

“What does this post mean?”

🧠 GPT
- autoregressive (predicts next word)
- used for generation
- good for writing text

Example use:

“Write a reply to this post”
